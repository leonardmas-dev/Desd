## 📋 Project Overview

This project analyses and models the business processes of **ProBuild Ltd**, a UK-based builder's merchant, using industry-standard modelling techniques and process automation tools.

The project covers:
- Socio-technical stakeholder analysis using **i\* modelling**
- High-level and operational **BPMN process modelling**
- Process automation using **Camunda**
- Critical evaluation of legal, ethical, social and professional considerations

## 🔄 How We Work (Scrum)

We use **Scrum** with a **Trello board** to manage tasks.

**Trello board lists:**
1. ⚡ Sprint Backlog — all tasks waiting to be picked up
2. 🔄 In Progress — tasks being actively worked on
3. 👀 Review — finished tasks waiting for a teammate to check
4. ✅ Done — approved and complete

**Workflow:**
1. Pick a card from Sprint Backlog
2. Move it to **In Progress** when you start
3. Move it to **Review** when done — a teammate must check it
4. Move it to **Done** once approved

## 📁 Uploading Files

When uploading files to this repo:
- Put BPMN files in `/bpmn`
- Put Camunda files/screenshots in `/camunda`
- Put i\* diagrams and stakeholder tables in `/diagrams`

- Use clear file names (e.g. `operational-bpmn-1-online-order.bpmn`)
